Neural Networks 01

Watch a neural network think.

One suspicious email. Four numbers. A prediction, a mistake, and the chain of gradients that teaches the model what to change.

Scroll to follow the computation

01 · Representation

The words become signals.

Before a neural network can reason about an email, the message must become numbers. Here we compress the example into four normalized features.

The network never sees “URGENT” directly. It receives x₁…x₄ — the numerical evidence extracted from the message.

02 · Weighted sum

Every connection has an opinion.

Each input sends a signal through a trainable weight. Strong positive weights amplify evidence; negative weights push in the opposite direction.

Watch the pulses converge on the hidden layer. Each neuron receives a different weighted view of the same email.

03 · Activation

Neurons decide what gets through.

The weighted sums enter ReLU. Positive evidence survives. Negative evidence is clamped to zero.

The third hidden neuron is still computed, but its negative pre-activation is clamped to 0. The amber state marks that ReLU decision explicitly.

04 · Prediction

Three hidden signals become one belief.

The hidden activations flow into the output neuron, forming a raw score — the logit. Sigmoid compresses that score into a probability.

The result is no longer an unrestricted number. It becomes P(spam), bounded between 0 and 1.

05 · Objective

Now the network learns how wrong it was.

The prediction meets the known target. Binary cross-entropy turns that disagreement into one scalar: the loss.

Training has one job: make this number smaller without being told directly which individual weight is responsible.

06 · Gradients

The error flows backward.

Backpropagation applies the chain rule from the loss back through every trainable connection.

The violet pulses are not data anymore. They are sensitivities — how strongly the loss reacts to each parameter.

07 · Gradient descent

Knowing the gradient changes the network.

Each weight moves a small distance opposite its gradient. The learning rate controls how large that move is.

The structure stays the same. The numbers inside it change — and that changes the next prediction.

08 · Training loop

Then it happens again. And again.

Forward pass. Loss. Backpropagation. Update. Repeated across examples and epochs, the network gradually finds parameters that reduce error.

A single update teaches the mechanism. Repetition turns that mechanism into learning.
